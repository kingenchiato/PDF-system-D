# 発注処理・天板並べ表（試作）

クラウドワークスの件、先に動きを見てもらう用です。

## 画面確認（Excel不要）

**https://kingenchiato.github.io/PDF-system-D/**

リポジトリ：https://github.com/kingenchiato/PDF-system-D

`index.html` をダウンロードして直接開いても同じです。

## 触り方

1. **PDF取込（デモ）** … 前回と同じ5営業所のファイル名で取込の流れを再現
2. **並べ表を作る** … 4×8尺原板への取り図（色＝営業所）
3. **請求書を出す** … 営業所ごとに発行
4. **ラベル印刷** … CODE39＋店舗名・寸法

「一括（並べ→請求→ラベル）」でまとめて回せます。

## 試作と本番の差

| 処理 | 試作 | 本番で合わせるもの |
|---|---|---|
| 発注の取込 | PDFデモ / CSV / 手入力 | PDFの項目位置（前回の5営業所レイアウト） |
| 並べ表 | 4×8尺に取り図 | 原板サイズ・刃幅・回転可否 |
| 請求書 | 営業所ごとに発行 | 御社の帳票・印影・振込先 |
| ラベル | CODE39 | 用紙サイズ・プリンタ |

サンプルは松屋各店・SUS天板で仮置きしています。品名・単価はマスタで差し替えます。

## VBA

`vba` に標準モジュールを置いてあります。xlsm にインポートして使います。

- `modNarabe.bas` … 並べ
- `modSeikyu.bas` … 請求
- `modLabel.bas` … ラベル台
- `modButtons.bas` … シート上のボタンから呼ぶ用

設定シート（例）

```
B2  原板ヨコ  2438
B3  原板タテ  1219
B4  刃幅      3
B7  穴あけ加算
B8  R加算
B9  溶接加算
```
